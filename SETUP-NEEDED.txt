2. STORE PRODUCTS — GOOGLE SHEET
   Lets you add/remove/edit store products without touching code.
   File: js/store-products.js

   Setup: create a Google Sheet, row 1 = column headers (any order):
         Name | SKU | Price | Description | Category | Colors | Sizes |
         Image | InStock | PreferredSide
     - SKU: short code like EMB-001, so orders coming through the contact
       form are easy to identify
     - Category column must be exactly one of:
         t-shirts, hoodies, uniform, keychains, posters, accessories
       The store page groups these under 4 top-level filters, with the
       specific category shown as a sub-filter when relevant:
         Clothing -> t-shirts, hoodies
         Uniform  -> uniform
         Merch    -> keychains, posters
         Accessories -> accessories
       (see CATEGORY_GROUPS in js/store-products.js if you add a new
       category and need to place it in one of these groups)
     - Colors / Sizes: comma-separated, e.g. "Black, White, Olive"
     - Image column: leave this BLANK for every normal product. The design
       artwork is now pulled automatically from the S3 bucket at
       <SKU>/<SKU>.png (built straight from the SKU column — see
       defaultDesignUrl in js/store-products.js), so there is nothing to
       paste in per row any more. Only fill this in to override a specific
       product (different file extension, artwork not in the bucket, an
       extra shot, etc.) — one or more full URLs, comma-separated; the
       first becomes the card thumbnail.
     - Photos column (optional): real photography of the finished product,
       comma-separated if you have more than one. These are NOT mocked up
       — they show as-is, alongside the generated mockup, in the "Buy
       This" popup gallery.
     - InStock: optional, put FALSE to hide a product without deleting it
     - PreferredSide (optional): put "Back" for a design that's meant to be
       worn as a back print — the card thumbnail and the "Buy This" popup
       will open on the back mockup instead of front. Leave blank (or put
       anything else) for a normal front print.
     - Optional extra column: BuyLink (custom "Buy Now" link per product;
       leave out to default to the contact form)
     - Share -> General access -> "Anyone with the link" -> Viewer
     - Copy the ID from the sheet's URL:

   What fires:
     PageView    every page
     Lead        checkout submitted (carries the cart subtotal),

                 newsletter form sent
