Re-encode shirt mockups

The shirt mockups are 2402×3481 PNGs of 2–3.7 MB each. They are 57% transparent, so JPEG is not an option — but WebP keeps the alpha at a fraction of the size.

Windows has no WebP encoder that PowerShell can reach, so this page borrows Chrome's: each mockup is drawn to a canvas, encoded with canvas.toDataURL('image/webp'), and POSTed to the dev server, which writes it next to the original. Originals are never touched.

Run it with serve.ps1 going, then open /tools/convert-mockups.html. Re-run it any time new mockups are added, then point js/shirt-colors.js at the .webp files.
